tensquads design system

The reference for how tensquads looks. It holds the ten squad mascots and the Agent-UI tokens that every screen uses.

Source: moeghashim/tensquads-design-systemTokens: Agent-UI version 1, 265 colours

Mascots

One frosted toy for each agent. Each body takes its shape from the place the agent is named after. Every mascot wears one lens over its right eye. The lens is the squad's mark. Each file comes as SVG, PNG with a clear background, and JPEG with a white background, at 1200 by 1480 pixels.

Shape

Why it fits
Petra opens the door to every job. It takes the request and hands each part to the right squadmate.
Pose
